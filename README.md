# Ten Points on a Sphere

An interactive spinning globe (orthographic projection, d3) with 10 pinned world cities.
Single self-contained HTML file — no external dependencies.

Live: https://bentoalson.github.io/globe-animation/

## Embed

```html
<iframe
  src="https://bentoalson.github.io/globe-animation/"
  title="Spinning globe with 10 world cities"
  loading="lazy"
  style="width: 100%; height: 600px; border: 0; display: block;">
</iframe>
```

Add `?transparent` to the URL to let the host page's background show through.
